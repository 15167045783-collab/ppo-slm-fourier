# PPO 相位型 SLM 傅里叶成像优化设计

## 目标

在现有空的 `PPO` 目录中创建一套独立项目，不修改 `moni` 或其余旧代码。程序每次读取 `PPO/data` 中用户指定的一张 `256×256` BMP 目标图，从随机 `8×8` 相位开始，由 PPO 反复调整相位；相位插值为 `256×256` 后经过简化的傅里叶焦平面模型形成模拟相机光强，训练目标是使模拟图像逐步逼近目标图。

第一版面向单目标、单环境训练，不训练能够同时处理 12 张图的通用策略，也不接入真实 SLM 或相机。

## 用户工作流

用户在本地或服务器进入 `PPO` 目录，通过命令指定单张目标图并启动训练：

```powershell
python train.py --target data/1.bmp --device auto
```

`--device auto` 优先使用可用 CUDA，否则使用 CPU。每次运行创建独立结果目录，不覆盖已有实验。提供 `--quick` 模式用于安装后快速检查完整流程，但快速模式不承诺重建质量。

## 数据与预处理

- 输入是 `PPO/data` 中的一张图片，当前数据为 `256×256`、24 位 BMP。
- 加载后转为单通道灰度、`float32`，数值归一化到 `[0, 1]`。
- 为避免总能量差异主导优化，目标图在进入环境前按最大值再次归一化；全黑图片应明确拒绝。
- 非法路径、无法解码的文件、非有限数值或全黑目标必须给出明确错误。
- 数据文件只读，训练不修改 `PPO/data`。

## 光学模型

环境维护 `8×8` 相位矩阵，所有元素始终位于 `[0, 2π)`。

每次成像按以下顺序执行：

1. 使用双线性插值将 `8×8` 相位扩展为 `256×256`。
2. 构造单位振幅复光场 `exp(i·phase)`。
3. 对光场执行正交归一化二维 FFT，并使用 `fftshift` 将零频移到中心。
4. 取复振幅模平方得到光强。
5. 用光强最大值归一化到 `[0, 1]`，形成单通道模拟相机图。

该模型表示简化的傅里叶焦平面成像，不包含波长、传播距离、像素间距、像差、噪声或相机非线性。光学传播只用于产生环境反馈，PPO 不通过它对相位直接反向传播。

## 强化学习环境

### 重置

每个 episode 使用可复现的随机种子生成新的 `8×8` 相位，元素均匀分布在 `[0, 2π)`。环境立刻模拟一次相机成像并记录初始 MSE。

### 观测

观测为 `3×256×256` 张量，三个通道依次为：

1. 目标灰度图；
2. 当前模拟相机图；
3. 当前 `8×8` 相位除以 `2π` 后双线性插值得到的相位通道。

观测必须为有限 `float32`，范围在 `[0, 1]`。

### 动作

Actor 输出 64 维高斯连续动作。环境对动作执行 `tanh` 限幅，重排为 `8×8`，乘以配置中的最大相位步长后累加到当前相位，再使用模运算环绕到 `[0, 2π)`。

### 奖励

以 MSE 为主要优化指标。设上一步误差为 `m_prev`、当前误差为 `m_cur`、限幅动作的均方值为 `a2`：

```text
reward = improvement_gain * (m_prev - m_cur)
         - mse_weight * m_cur
         - action_penalty * a2
```

改善项鼓励每一步降低误差，当前误差项防止长期来回振荡，动作惩罚抑制无意义的大幅修改。三个系数均由配置集中管理。

### 结束条件

满足任一条件时 episode 结束：

- 当前 MSE 小于或等于 `target_mse`，视为提前达到目标；
- 达到 `episode_length` 最大步数。

达到阈值只结束当前训练并保存结果，不生成新的目标。未达到阈值时，训练最多执行 `total_steps`，确保程序可终止。

## PPO 算法与网络

- 使用共享卷积编码器提取 `3×256×256` 观测特征。
- Actor 输出 64 维动作均值，并维护可学习的对数标准差。
- Critic 输出单个状态价值。
- 使用 clipped PPO objective、GAE、价值损失、熵奖励和梯度范数裁剪。
- rollout 存储在 CPU，更新时按小批量搬到选择的设备，以控制显存使用。
- 训练过程中相机反馈和奖励与自动求导图断开；只有 Actor-Critic 的策略和值函数参与反向传播。

所有超参数放在不可变配置对象中。默认配置用于正式训练，快速配置用于测试与冒烟运行。

## 训练过程

训练循环执行以下步骤：

1. 加载目标图并创建环境、Actor-Critic、PPO agent。
2. 重置环境，记录初始相位、初始模拟相机图和初始 MSE。
3. 策略根据观测采样 64 维动作，环境更新相位并返回新图、奖励和指标。
4. 持续追踪整个训练历史中 MSE 最低的相位与相机图，而不是只使用最后一步。
5. rollout 满后计算 GAE 并更新 PPO；episode 结束则按确定种子序列重新随机初始化。
6. 达到 `target_mse` 或 `total_steps` 后结束训练。
7. 保存最佳结果、训练指标和可恢复 checkpoint。

训练应固定 Python、NumPy 和 PyTorch 随机种子。在相同设备和 PyTorch 实现允许的范围内提供可复现结果。

## 输出

每次运行创建 `results/<run-name>/`。若名称已存在，则追加编号而不是覆盖。目录至少包含：

- `best_phase.npy`：最佳 `8×8` 浮点相位，单位为弧度；
- `slm_8bit.png`：将最佳相位从 `[0, 2π)` 映射到 `[0, 255]` 的 `8×8` 灰度投图；
- `simulated_camera.png`：最佳 `256×256` 模拟相机图；
- `comparison.png`：目标图、初始相机图、最佳相机图、绝对误差图和最佳相位；
- `training_curves.png`：每个环境步的 MSE、奖励和 PSNR；
- `checkpoint_best.pt`：网络、优化器、配置、步数和最佳相位；
- `metrics.json`：目标路径、种子、停止原因、初始/最佳 MSE、PSNR、改善比例和最佳步数。

所有路径都相对于 `PPO` 项目根解析，使项目复制到 Linux 服务器后仍可直接运行。

## 错误处理

- 用户显式选择 `cuda` 但 CUDA 不可用时立即报错，不静默回退。
- 环境拒绝形状错误、非浮点、NaN、Inf 或超出有效范围的目标、观测、动作和相机图。
- FFT 结果最大值无效或为零时立即报错。
- PPO 更新前检查 rollout 已完成 GAE，且批次中的所有值有限。
- 保存结果前创建目录；已有运行目录不得被覆盖。

## 测试与验收

采用测试驱动开发。自动化测试至少覆盖：

- 图片加载、灰度转换、归一化、全黑图拒绝和错误路径；
- `8×8` 相位双线性插值为 `256×256`，FFT 光强形状、范围和有限性；
- 相位到 8 位 SLM 图的端点、环绕和形状；
- reset 的随机相位范围、种子可复现性和观测结构；
- step 的相位环绕、奖励公式、MSE 信息与两类结束条件；
- GAE、rollout 校验和 PPO 参数实际更新；
- 输出文件完整性、运行目录不覆盖；
- 命令行参数与快速模式的端到端冒烟流程。

完成验收需要：

1. `PPO` 的完整测试套件通过；
2. 快速模式能从指定 BMP 运行到结束并生成全部约定输出；
3. 正式默认配置具备有限训练步数和阈值停止机制；
4. 最佳结果按训练中最低 MSE 选取；
5. 原有 `moni` 和 `PPO/data` 文件未被修改。

快速模式只验证闭环和输出，不以短训练中必然出现明显图像改善作为硬性条件。正式训练的基本质量指标为 `best_mse < initial_mse`；具体可达到的误差取决于目标图、8×8 相位自由度、训练时长和随机种子。

## 非目标与后续扩展

第一版不包含真实硬件、物理参数传播、多目标通用策略、并行环境、断点续训界面或超参数搜索。未来若接入真实 SLM/相机，可新增与模拟捕获相同接口的硬件后端，而不改变 PPO 核心逻辑。
